# 자원 변환 체인

> Resource Conversion Chain / Production Chain
> 한 줄 정의: 원료 → 중간재 → 완성품으로 이어지는 다단계 가공 사슬.

## 근본 원리 ★
**깊이는 단계 수에서 나온다.** 사슬이 길수록 계획·물류·병목 관리라는 "최적화할 거리"가 생기고, 플레이어는 시스템을 *설계하는* 주체가 된다.

## 설계 손잡이 (Parameters) ★
- **사슬 깊이** — 2단계 ◁▷ 수십 단계 → 깊을수록 최적화 재미·진입장벽 동시 상승.
- **분기/합류** — 선형 ◁▷ 그물형 → 그물형이면 배치·물류 퍼즐이 폭발.
- **레시피 자유도** — 고정 ◁▷ 플레이어 정의 → 자유로우면 창의성, 단 밸런싱 난이도↑.
- **단계 가시성** — 숨김 ◁▷ 명시 → 사슬이 깊을수록 시각화가 필수.
