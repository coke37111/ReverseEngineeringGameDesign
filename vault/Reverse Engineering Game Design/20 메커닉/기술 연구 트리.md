# 기술 연구 트리

> Tech / Research Tree
> 한 줄 정의: 자원·노동·도전으로 신기술을 단계적으로 해금하는 분기 구조.

## 근본 원리 ★
**선택의 환상 + 방향 제시.** 트리는 "내가 길을 고른다"는 주체감을 주면서 동시에 복잡도 게이팅으로 학습 순서를 통제한다. [[진행 곡선]]의 가장 흔한 구현체.

## 설계 손잡이 (Parameters) ★
- **연료 출처** — 자원 ◁▷ 직접 생산 ◁▷ 도전 → 생산/도전형일수록 진행=플레이 일체.
- **분기 폭** — 좁음(거의 선형) ◁▷ 넓음 → 넓으면 빌드 다양성·리플레이성.
- **되돌림** — 불가 ◁▷ 리스펙 가능 → 가능하면 실험 부담↓.
- **가시 범위** — 다 보임 ◁▷ 안개(점진 공개) → 안개는 발견의 재미.

## 함정 & 트레이드오프
후반 해금 고갈 → 동기 소실. 분기가 가짜(한 길이 명백히 우월)면 선택이 무의미.
