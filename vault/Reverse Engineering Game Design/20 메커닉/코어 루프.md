# 코어 루프

> Core Loop
> 한 줄 정의: 플레이어가 반복하는 "관찰 → 결정 → 행동 → 보상" 사이클.

## 근본 원리 ★
인간은 *예측 가능한 보상 + 약간의 변수*에 반복적으로 끌린다. 여러 시간 척도의 보상이 겹치면 "짧게도 길게도 만족"해 이탈 지점이 사라진다("한 턴만 더").

## 설계 손잡이 (Parameters) ★
- **루프 길이** — 초 ◁▷ 시간 → 짧으면 손맛/긴장, 길면 전략/성취. 보통 3층(분/세션/메타)으로 중첩.
- **층위 수** — 1층 ◁▷ 3층+ → 많을수록 다양한 플레이 세션을 흡수(짧은 휴식~장시간).
- **결정 밀도** — 낮음(자동) ◁▷ 높음(매 순간 선택) → 높으면 몰입·피로, 낮으면 방치·여유.
- **변수성** — 결정론적 ◁▷ 무작위 → 높으면 신선함, 낮으면 숙달감.

## 게임별 손잡이 설정 (비교 = 인사이트) ★
| 게임 | 핵심 손잡이 설정 | 만들어진 느낌 |
|---|---|---|
| [[Factorio]] | 분=배치/배선, 세션=라인완성, 메타=로켓. 결정밀도 높음 | 끝없는 "다음 한 칸" |
| [[RimWorld]] | 분=대응, 메타=이야기. 변수성 높음([[AI 스토리텔러]]) | 예측 못 한 드라마 |
| [[Against the Storm]] | 세션 루프를 1~2h로 명확히 닫음([[로그라이트 메타 진행]]) | 경쾌한 "한 판 더" |
| [[Cities Skylines]] | 메타(도시 성장) 중심, 분 단위는 느슨 | 느긋한 관조형 성장 |

## 함정 & 트레이드오프
분 단위가 지루하면 자동화 후 공허, 메타가 약하면 장기 동기 소멸. 결정 밀도가 너무 높으면 번아웃.
