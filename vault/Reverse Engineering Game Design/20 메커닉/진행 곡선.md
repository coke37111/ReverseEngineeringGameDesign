# 진행 곡선

> Progression / Unlock Pacing
> 한 줄 정의: 새 콘텐츠·능력이 해금되는 속도와 순서.

## 근본 원리 ★
**복잡도는 한 번에 쏟지 말고 양파처럼 벗긴다.** 인간은 늘 "다음 목표(당근)"가 보일 때 동기를 유지한다. 진행 곡선은 복잡도를 시간축에 분산해 압도와 권태 사이를 줄타기한다.

## 설계 손잡이 (Parameters) ★
- **해금 속도** — 느림 ◁▷ 빠름 → 초반 느리면 이탈, 빠르면 압도.
- **해금 트리거** — 비용 기반(자원) ◁▷ 도전 기반(목표 달성) → 도전 기반이 성취감↑.
- **분기도** — 선형 ◁▷ 분기 → 분기면 선택·리플레이성.
- **진행=플레이 일체도** — 분리 ◁▷ 일체 → 일체일수록(성장이 곧 플레이) 몰입↑.
