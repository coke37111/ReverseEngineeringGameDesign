# 수직 건설

> Vertical Building
> 한 줄 정의: 높이(Z축)를 설계 변수로 열어 같은 면적에서 복잡도·표현을 확장하는 것.

## 근본 원리 ★
**차원을 하나 더 열면 같은 맵에서 설계 공간이 지수적으로 커진다.** 중력·유체·온도와 결합하면 새 물류 문제가 자생한다.

## 설계 손잡이 (Parameters) ★
- **층 상호작용** — 독립 ◁▷ 결합(열 상승·물 낙하) → 결합이 깊이.
- **수직 이동 비용** — 무료 ◁▷ 펌프/엘리베이터 필요 → 비용이 새 퍼즐.
- **가독성 지원** — 약함 ◁▷ 단면/층 전환 뷰 → 가독성이 성패.
- **파괴 가능성** — 고정 ◁▷ 굴착/붕괴 → 가능하면 토목 창의성.
