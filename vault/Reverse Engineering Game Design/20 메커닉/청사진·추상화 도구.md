# 청사진·추상화 도구

> Blueprints & Abstraction Tools
> 한 줄 정의: 손노동을 복사·재사용·자동화로 추상화해 복잡도 폭발을 막는 QoL 장치.

## 근본 원리 ★
**복잡도가 커질수록 "같은 걸 반복 배치"하는 손노동이 늘고, 추상화하지 않으면 후반이 권태로 붕괴한다.** 추상화 도구는 플레이어를 노동자에서 설계자로 승격시킨다.

## 설계 손잡이 (Parameters) ★
- **제공 타이밍** — 이르게 ◁▷ 복잡도와 동기화 → 동기화가 정답.
- **추상화 단위** — 단일 복사 ◁▷ 모듈/청사진/봇 자동건설 → 클수록 후반 노가다 흡수.
- **자동 판단 위임** — 없음 ◁▷ 정책·로직(센서) → 위임할수록 반복 결정 제거.
- **학습 비용** — 낮음 ◁▷ 높음 → 강력할수록 배우기 어려움.
