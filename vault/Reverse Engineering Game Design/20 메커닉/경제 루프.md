# 경제 루프

> Economy / Sources & Sinks
> 한 줄 정의: 자원이 생성(소스)되고 소멸(싱크)되는 순환 구조.

## 근본 원리 ★
**의미 있는 결정 = 희소성.** 경제의 본질은 희소성을 인위적으로 유지하는 것이다. 자원이 남아돌면 결정이 사라지고, 너무 마르면 스트레스가 된다. 좋은 경제는 "늘 약간 부족한" 상태를 설계한다.

## 설계 손잡이 (Parameters) ★
- **소스 속도** — 느림 ◁▷ 빠름 → 성장 템포.
- **싱크 강도/종류** — 약함 ◁▷ 강함 → 고임(인플레) 방지의 핵심. *대부분의 경제 실패는 싱크 부재.*
- **화폐 가짓수** — 1개 ◁▷ 다중 → 많을수록 관리 깊이·복잡도.
- **변환 사슬 깊이** — 얕음 ◁▷ 깊음 → [[자원 변환 체인]]으로 연결.
- **가격 동성** — 고정 ◁▷ 동적(수요변동) → 동적이면 시장 플레이가 생김.
