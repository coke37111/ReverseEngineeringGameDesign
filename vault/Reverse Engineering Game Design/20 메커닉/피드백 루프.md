# 피드백 루프

> Feedback Loop
> 한 줄 정의: 시스템의 출력이 다시 입력에 영향을 주는 순환. 양/음 두 종류.

## 근본 원리 ★
**단순 규칙도 루프로 엮이면 창발한다.** 양 피드백(눈덩이)은 성장의 쾌감을, 음 피드백(자기 조절)은 긴장을 만든다. 둘의 배합이 게임의 "느낌"을 결정한다.

## 설계 손잡이 (Parameters) ★
- **양 피드백 강도** — 약함 ◁▷ 강함 → 강하면 빠른 성장감·후반 붕괴 위험.
- **음 피드백 강도** — 약함 ◁▷ 강함 → 강하면 긴장 유지·답답함 위험.
- **지연(lag)** — 즉시 ◁▷ 지연 → 지연이 클수록 계획·예측 게임.
- **가시성** — 숨김 ◁▷ 명시 → 루프가 안 보이면 불공정하게 느껴짐.
